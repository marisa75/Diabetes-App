Wichtigste Datenflüsse

Dexcom-Anbindung & Glukose

1
Home leitet auf /auth/dexcom weiter.
2
Backend redirected zur Dexcom-Login-Seite.
3
Dexcom ruft /callback mit code auf.
4
Callback.tsx sendet den Code an /auth/dexcom/token.
5
Backend tauscht ihn gegen ein Access-Token und speichert es.
6
Home lädt Werte über /api/glucose/latest → GlucoseChart.

Nährwert-Scan (Foto → BE)

1
NutritionScan nimmt Foto auf (Kamera / Barcode via @zxing).
2
Bild als Base64 an /api/analyze-food.
3
Backend sendet es an LogMeal (Segmentierung).
4
Abfrage von Nährwerten & Zutaten zur erkannten Mahlzeit.
5
Backend berechnet Kohlenhydrate, Zucker, Ballaststoffe & BE.
6
Aufbereitetes JSON zurück an die App-Ansicht.
